# iamunified.info

> One person. One identity. One unified digital footprint.

**iamunified.info** is a web application that gathers your entire digital life in one place — turning scattered accounts into a single, clear view so you can own your footprint and understand your presence.

## Project structure

```
index.html   — Landing page (hero, features, how-it-works, CTA, footer)
styles.css   — Design system and component styles
app.js       — Scroll animations, smooth-scroll polyfill, form handling
```

## Getting started

Open `index.html` directly in any modern browser — no build step required.
